# TypeScript Learning Hub

TypeScript is JavaScript with labels on your data. The labels (types) help you catch mistakes before the code runs.

> **Like I'm 5:** JavaScript is a box of toys where you can put anything in any slot. TypeScript is the same box, but each slot has a label, like "only cars go here". If you put a duck in the car slot, the label catches it before you play.

This folder has two parts. Pick the one you need.

| Section | What it is | Start here |
|---------|------------|-----------|
| **Concepts** | Topic-by-topic reference, from setup to advanced types, with code snippets and a "Like I'm 5" explanation for each topic | [concepts/README.md](concepts/README.md) |
| **Interview Q&A** | Questions and answers for experienced developers, each with a "Like I'm 5" explanation | [interviewQnA/README.md](interviewQnA/README.md) |

New to TypeScript? Read the concepts in order, then practise with the interview questions.
