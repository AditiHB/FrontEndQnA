## Difficulty legend

- **Core**: expected of every TypeScript developer.
- **Advanced**: expected of a senior developer.
- **Architect**: expected of a lead or architect candidate.

## How to use this

1. Read the question, answer it out loud in 60–90 seconds, then compare with the notes.
2. Use the "Like I'm 5" line to recall the idea, then the answer for the detail.
3. For each topic, follow the link in the [concepts reference](../concepts/README.md) for code examples.
