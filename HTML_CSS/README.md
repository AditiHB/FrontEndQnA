# HTML and CSS Learning Hub

HTML builds the **structure** of a web page. CSS gives it **looks and layout**. Together they are the foundation of everything you see in a browser.

> **Like I'm 5:** HTML is the skeleton of a page (a heading here, a picture there). CSS is the clothes and the posture: the colours, the sizes, and how the page bends to fit a tiny phone or a huge monitor.

This folder has one big, hands-on course and the things that go with it.

| Section | What it is | Start here |
|---------|------------|-----------|
| **Tutorial** | A step-by-step course that builds one real website, the **Bunny Bakery**, from an empty file to a finished, accessible, **responsive** site with dark mode. 20 short lessons (0 to 19), each explained like you're 5. It covers HTML, CSS, Flexbox, Grid, responsive design and modern CSS, and then rebuilds the same site with **Tailwind CSS v4** | [tutorial/README.md](tutorial/README.md) |
| **Playgrounds and games** | Interactive pages that open with a double-click: a **Flexbox** playground and a **Grid** playground to move things around, and two games (8 Flexbox levels and 9 Grid levels) where you write the CSS and the page checks your answer | [tutorial/playgrounds](tutorial/playgrounds) |
| **Finished projects** | The complete Bunny Bakery site, once in plain HTML and CSS and once with Tailwind, to open and compare with when you are stuck | [tutorial/finished-project](tutorial/finished-project) |

**You need no experience.** You need a browser, a text editor (VS Code is free and friendly) and a folder. Only the last two lessons use Node.js, to run Tailwind's build tool.

New to HTML and CSS? Start at Lesson 0 and follow the course in order. Already know the basics? Jump to **Part 3 (Flexbox and Grid)**, **Part 4 (responsive design and modern CSS)** or **Part 5 (Tailwind)**: every lesson says what it expects you to know.

## What you will learn

- **HTML:** the structure of a page, text, links, lists and images, semantic elements, accessibility, forms and tables.
- **CSS:** selectors, the cascade and specificity, the box model, colours, fonts, units, custom properties, backgrounds, shadows and transitions.
- **Layout:** Flexbox, Grid, positioning and stacking, with playgrounds and games to practise.
- **Responsive design:** the viewport, media queries, mobile-first CSS, fluid sizes, a no-JavaScript mobile menu, **container queries**, responsive images, dark mode and print styles.
- **Modern CSS:** nesting, `:has()`, `color-mix()`, logical properties (right-to-left support), cascade layers and subgrid.
- **Tailwind CSS v4:** utility-first CSS, a theme, variants, components, and a full rebuild of the site.
