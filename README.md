# FrontEndQnA
Repository intended to have interview QnA for Front end technologies

## Structure

```
FrontEndQnA/
├── angular/
│   ├── README.md               # Angular learning hub: links to the three sections below
│   ├── tutorial/               # step-by-step course: build a toy shop in 37 chapters (Angular 22)
│   │   ├── README.md           # roadmap and concept-to-chapter map
│   │   ├── 00 to 37 chapter files
│   │   ├── toy-shop-final/     # the finished project
│   │   ├── toy-lab-final/      # library, web component and schematic (chapters 30, 31)
│   │   ├── toy-federation-final/  # micro-frontend demo (chapter 32)
│   │   ├── extras/             # practice files and the upgrade practice app
│   │   └── images/             # screenshots
│   ├── interviewQnA/           # interview Q&A (8+ years, Angular + Java)
│   │   ├── README.md
│   │   └── 01 to 10 topic files
│   └── concepts/               # topic-wise reference, setup to deployment
│       ├── README.md
│       ├── 01 to 35 topic files  # each starts with a "Like I'm 5" summary
│       └── 36-a-to-z-glossary.md
├── react/
│   ├── README.md
│   ├── tutorial/               # 24-lesson build-along course (a toy shop), explained like you're 5
│   ├── interviewQnA/           # interview Q&A, each question has a "Like I'm 5" line
│   └── concepts/               # topic-wise reference with a glossary
├── javascript/
│   ├── README.md
│   ├── tutorial/               # build a Lemonade Stand step by step, one step per concept
│   │   ├── README.md
│   │   ├── 00 to 23 step files   # each step: play, build, try it yourself, checkpoint
│   │   └── finished-project/     # the complete, tested project to compare with
│   ├── interviewQnA/           # interview Q&A, each question has a "Like I'm 5" line
│   └── concepts/               # topic-wise reference with a glossary
├── typescript/
│   ├── README.md
│   ├── interviewQnA/
│   └── concepts/
└── HTML_CSS/
    ├── README.md               # HTML and CSS learning hub
    └── tutorial/               # 20-lesson build-along course: the Bunny Bakery, from HTML basics to responsive design and Tailwind CSS
        ├── README.md           # roadmap and lesson list
        ├── 00 to 19 lesson files  # each lesson: story, steps, try it yourself, check yourself
        ├── playgrounds/        # Flexbox and Grid playgrounds and games (open with a double-click)
        └── finished-project/   # the complete site, in plain HTML/CSS and with Tailwind CSS
```

Each technology follows the same pattern: a `README.md` hub, a `concepts/` folder for topic-by-topic reference, and an `interviewQnA/` folder for questions and answers. Angular, React and JavaScript also have a `tutorial/` folder, a step-by-step build that teaches every concept hands-on. `HTML_CSS/` is a tutorial-first course for beginners (the foundation under all the others). Future frameworks can be added as sibling folders using this pattern.
