# 23. JavaScript A to Z Glossary

| Letter | Term | Meaning | Lesson |
|--------|------|---------|--------|
| **A** | `async` / `await` | Write promise code that reads like normal code. | [12](12-promises-and-async-await.md) |
| **A** | AbortController | Cancels fetch or event listeners. | [16](16-dom-and-events.md), [17](17-fetch-and-web-apis.md) |
| **A** | Arrow function | Short function syntax with lexical `this`. | [04](04-functions.md), [11](11-this-and-binding.md) |

| **C** | Call stack | The list of functions currently running. | [01](01-how-javascript-runs.md) |
| **C** | Class | A blueprint for objects. | [10](10-classes.md) |
| **C** | Closure | A function that remembers variables from where it was created. | [05](05-closures.md) |
| **C** | Coercion | Automatic conversion between types. | [03](03-data-types-and-coercion.md) |
| **D** | Debounce | Run a function after input has stopped for a while. | [20](20-performance-and-memory.md) |

| **E** | Event delegation | One listener on a parent handles events for many children. | [16](16-dom-and-events.md) |

| **G** | Garbage collection | Automatic memory cleanup. | [20](20-performance-and-memory.md) |
| **G** | Generator | A function that pauses with `yield`. | [14](14-iterators-and-generators.md) |
| **H** | Hoisting | Declarations are known before their line runs. | [02](02-variables-and-scope.md) |
| **I** | Immutability | Don't change values; create new ones. | [18](18-immutability-and-pure-functions.md) |
| **I** | Iterator | An object with `next()` that yields values. | [14](14-iterators-and-generators.md) |
| **I** | `Intl` | Built-in locale formatting. | [19](19-strings-numbers-and-dates.md) |
| **J** | JSON | Text format for data: `JSON.parse` and `JSON.stringify`. | [17](17-fetch-and-web-apis.md) |
| **L** | Lexical scope | Scope decided by where code is written. | [02](02-variables-and-scope.md) |
| **M** | Microtask | Promise callbacks that run before timers. | [13](13-event-loop-and-timers.md) |
| **M** | Module | A file with `import` and `export`. | [09](09-modules.md) |
| **N** | `null` vs `undefined` | Intentional empty vs not set. | [03](03-data-types-and-coercion.md) |
| **N** | Nullish coalescing (`??`) | Default only for `null` or `undefined`. | [03](03-data-types-and-coercion.md) |
| **O** | Optional chaining (`?.`) | Stops at `null` or `undefined` safely. | [06](06-objects-and-prototypes.md) |
| **P** | Prototype | The parent object that an object inherits from. | [06](06-objects-and-prototypes.md) |
| **P** | Promise | A receipt for a value that will arrive later. | [12](12-promises-and-async-await.md) |
| **P** | Pure function | Same input, same output, no side effects. | [18](18-immutability-and-pure-functions.md) |
| **Q** | `querySelector` | Finds the first element matching a CSS selector. | [16](16-dom-and-events.md) |
| **R** | Rest parameter | `...args` collects the remaining values. | [08](08-destructuring-spread-and-rest.md) |
| **S** | Spread | `...` expands an array or object. | [08](08-destructuring-spread-and-rest.md) |
| **S** | `Symbol` | A unique primitive value. | [03](03-data-types-and-coercion.md) |
| **S** | Strict mode | Stricter rules; modules always use it. | [11](11-this-and-binding.md) |
| **T** | Temporal dead zone | Time between entering scope and declaring `let`/`const`. | [02](02-variables-and-scope.md) |
| **T** | Throttle | Run at most once per time window. | [20](20-performance-and-memory.md) |
| **T** | `this` | Depends on how a function is called. | [11](11-this-and-binding.md) |
| **T** | Truthy / falsy | Values treated as true or false in conditions. | [03](03-data-types-and-coercion.md) |
| **V** | `var` | Old, function-scoped variable. | [02](02-variables-and-scope.md) |
| **W** | Web Worker | Runs code in a background thread. | [17](17-fetch-and-web-apis.md) |
| **W** | WeakMap | A map whose keys can be garbage collected. | [20](20-performance-and-memory.md) |
| **X** | XSS | Cross-site scripting: attacker code runs in your page. | [21](21-security.md) |
| **Y** | `yield` | Pauses a generator and returns a value. | [14](14-iterators-and-generators.md) |
| **Z** | Zero-based index | Arrays and months start counting at 0. | [07](07-arrays-and-iteration.md), [19](19-strings-numbers-and-dates.md) |
