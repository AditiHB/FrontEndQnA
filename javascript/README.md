# JavaScript Learning Hub

JavaScript is the language that makes web pages do things. It runs in the browser and on servers (Node.js).

> **Like I'm 5:** JavaScript is the magic that makes a picture move when you press a button. HTML is the picture, CSS is its paint, and JavaScript is the magic that makes it dance.

This folder has two parts. Pick the one you need.

| Section | What it is | Start here |
|---------|------------|-----------|
| **Concepts** | Topic-by-topic reference, from how JavaScript runs to the DOM, async code, and tooling, with code snippets and a "Like I'm 5" explanation for each topic | [concepts/README.md](concepts/README.md) |
| **Interview Q&A** | Questions and answers for experienced developers, each with a "Like I'm 5" explanation | [interviewQnA/README.md](interviewQnA/README.md) |

New to JavaScript? Read the concepts in order, then practise with the interview questions.
