# Angular Learning Hub

This folder has three parts. Pick the one you need.

| Section | What it is | Start here |
|---------|------------|-----------|
| **Tutorial** | A step-by-step, "Like I'm 5" course. You build one real project (an online toy shop) in 37 chapters and learn every concept from the concepts reference along the way. Uses Angular 22. | [tutorial/README.md](tutorial/README.md) |
| **Concepts** | Topic-by-topic reference, from setup to deployment, with code snippets and a simple "Like I'm 5" explanation for each topic | [concepts/README.md](concepts/README.md) |
| **Interview Q&A** | Questions and answers for an 8-year Angular + Java full stack developer | [interviewQnA/README.md](interviewQnA/README.md) |

New to Angular? Do the **tutorial** first. Use the **concepts** as a short reference when you want the details of one topic, then practise with the **interview questions**.
