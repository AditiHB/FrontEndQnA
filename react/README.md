# React Learning Hub

React is a library for building user interfaces out of small, reusable pieces called components.

> **Like I'm 5:** React is a LEGO kit for web pages. Each brick is a component. When a brick's data changes, React redraws only that brick, not the whole castle.

This folder has two parts. Pick the one you need.

| Section | What it is | Start here |
|---------|------------|-----------|
| **Concepts** | Topic-by-topic reference, from components and hooks to routing, data fetching, React 19, and deployment, with code snippets and a "Like I'm 5" explanation for each topic | [concepts/README.md](concepts/README.md) |
| **Interview Q&A** | Questions and answers for experienced developers, each with a "Like I'm 5" explanation | [interviewQnA/README.md](interviewQnA/README.md) |

New to React? Read the concepts in order, then practise with the interview questions.
